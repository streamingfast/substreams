# Foundational Stores

Foundational stores are available for various blockchain ecosystems, each optimized for specific data patterns and use cases. To have StreamingFast run a store populated by a package like these, see the [Substreams Feed Hosted Store Guide](../../hosted-services/hosted-store-substreams-feed.md). To push your own data over gRPC instead, see the [Remote Feed Hosted Store Guide](../../hosted-services/hosted-store-remote-feed.md). For the full hosted offering (sinks and stores), see [Hosted Services](../../hosted-services/hosted-services.md).

### Ethereum
- [ERC20 Token Metadata](ethereum/erc20-token-metadata.md) - Store and serve ERC20 token metadata and balances

### Solana
- [SPL Initialized Account](solana/spl-initialized-account.md) - Track SPL token account initialization and ownership
