# Foundational Stores

Chain-specific foundational stores, each optimized for specific blockchain data patterns and use cases.

## Available Stores

### Ethereum
- [ERC20 Token Metadata](ethereum/erc20-token-metadata.md) - Store and serve ERC20 token metadata and balances

### Solana
- [SPL Initialized Account](solana/spl-initialized-account.md) - Track SPL token account initialization and ownership
